برای استفاده از API کامل، ثبت‌نام کنید و کلید بسازید — ۱۰۰۰ درخواست رایگان هر روز

مستندات API

GET/api/v1/search

جست‌وجوی وب. احراز هویت با هدر X-API-Key انجام می‌شود.

پارامترنوعتوضیح
qstring *عبارت جست‌وجو (الزامی)
langstringزبان نتایج: fa, en, all, auto
sitestringمحدودسازی به یک سایت، مثل wikipedia.org
countintتعداد نتایج (۱ تا ۵۰، پیش‌فرض ۱۰)

cURL

curl -H "X-API-Key: nvsk_YOUR_KEY" \
  "BASE_URL/api/v1/search?q=AI&lang=fa&count=5"

Python

import httpx
r = httpx.get("BASE_URL/api/v1/search",
  params={"q": "AI", "lang": "fa"},
  headers={"X-API-Key": "nvsk_YOUR_KEY"})
print(r.json()["results"])
